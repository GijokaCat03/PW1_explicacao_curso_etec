O que é Banco de Dados?

A disciplina de Banco de Dados no primeiro ano do curso de Desenvolvimento de Sistemas da ETEC é o pilar fundamental para compreender como as informações são organizadas, armazenadas e gerenciadas pelos softwares modernos. Todo sistema relevante — desde redes sociais e plataformas de streaming até bancos e e-commerces — depende de uma estrutura de dados bem planejada para funcionar com segurança e rapidez. É exatamente nessa matéria que o estudante aprende a deixar de ver os dados como meros textos em uma tela para entendê-los como ativos estruturados e interconectados.

O aprendizado começa com a fase de modelagem e projeto de banco de dados, na qual os alunos aprendem a abstrair regras de negócio do mundo real e transformá-las em esquemas lógicos. Nessa etapa conceitual, os estudantes utilizam o Modelo Entidade-Relacionamento (MER) e constroem Diagramas Entidade-Relacionamento (DER), definindo quais entidades farão parte do sistema, seus atributos, chaves primárias, chaves estrangeiras e os relacionamentos entre elas. Além disso, a disciplina ensina as regras de normalização de dados, uma técnica essencial para evitar a duplicidade de informações e garantir a integridade dos registros salvos no banco.

Após dominar a parte de arquitetura e planejamento, os alunos partem para a prática com a linguagem SQL (Structured Query Language) nos laboratórios de informática, utilizando Sistemas Gerenciadores de Banco de Dados (SGBD) como MySQL ou PostgreSQL. Nessa fase mão na massa, a turma aprende os comandos DDL para criar tabelas e bancos, os comandos DML para inserir, atualizar e deletar dados, e explora a fundo os comandos DQL para realizar consultas simples e complexas. Todo esse conhecimento é integrado aos projetos desenvolvidos nas disciplinas de Programação Web e Algoritmos, permitindo que o estudante crie aplicações completas capazes de salvar, buscar e manipular dados reais em tempo de execução.
