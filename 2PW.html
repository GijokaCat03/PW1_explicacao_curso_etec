O que é a Programação de Web 1?

A disciplina de Programação Web 1 é uma das mais aguardadas e dinâmicas do primeiro ano no curso de Desenvolvimento de Sistemas da ETEC. É através dela que o estudante faz a sua transição do desenvolvimento de código puramente lógico para a criação visual e interativa da internet, aprendendo a construir páginas web modernas a partir do zero. O objetivo principal da matéria é introduzir o conceito de front-end, ensinando como a estrutura, o design e o comportamento de um site se conectam para oferecer uma boa experiência ao usuário final.

O aprendizado é dividido de forma muito clara em três pilares fundamentais. Inicialmente, os alunos aprendem a utilizar o HTML5 para definir a estrutura e a semântica dos elementos na tela, como títulos, parágrafos, formulários, tabelas e mídias. Em seguida, a disciplina introduz o CSS3, permitindo estilizar esses elementos com cores, tipografia, espaçamentos e layouts modernos (como Flexbox e Grid), além de ensinar a criar páginas totalmente responsivas que se adaptam tanto a telas de computadores quanto a dispositivos móveis. Por fim, o curso insere os primeiros passos em JavaScript, trazendo interatividade para a página através da manipulação de eventos, validação de campos de formulário e pequenas animações.

Todo o conteúdo é trabalhado com forte apelo prático em laboratório, onde os alunos desenvolvem desde projetos simples — como páginas pessoais e blogs — até a interface visual de sistemas web mais elaborados. Além do código em si, a matéria também aborda boas práticas de padronização, noções de acessibilidade e a utilização de ferramentas de desenvolvimento do próprio navegador para testar e depurar a interface. Ao concluir o primeiro ano em Programação Web 1, o estudante já possui a bagagem necessária para criar protótipos e interfaces funcionais, preparando o terreno para o aprendizado de linguagens back-end e integração com bancos de dados nos anos seguintes.

Essa experiência prática é ampliada pelo uso de bibliotecas e frameworks modernos do mercado, como o Bootstrap, que auxiliam na criação rápida de interfaces profissionais e alinhadas às tendências visuais atuais. Com isso, os projetos desenvolvidos pelos alunos deixam de ser meros exercícios escolares e passam a compor um portfólio real, demonstrando na prática a capacidade do estudante de transformar requisitos de design em sistemas web totalmente funcionais.
